# Processed Data

This directory contains the processed data files and intermediate outputs generated by the statistical analysis and trophic reconstruction pipeline. These files are utilized by the R scripts located in the `scripts/statistics/` directory.


### Stable Isotope Analysis (SIA) Data
The `reference_sia/` subdirectory contains the finalized CSV outputs for the trophic level reconstruction, which are utilized specifically by the `scripts/statistics/08_Stable_Isotope_Analysis.R` script.

Inside `reference_sia/31_full_reconstruction/`, you will find:
* `31_SIA_predator_samples_FINAL.csv` - Individual predator SIA values.
* `31_SIA_predator_summary_FINAL.csv` - Summary statistics for the predators.
* `31_SIA_reference_individuals.csv` - Baseline reference individual data.
* `31_SIA_reference_summary_FINAL.csv` - Summary statistics for the baseline references.
