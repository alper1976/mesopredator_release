# Stable Isotope Analysis (SIA) Data

This directory contains the processed Stable Isotope Analysis (SIA) reference and predator data used for trophic level reconstruction.

These datasets are specifically utilized by the `scripts/statistics/08_Stable_Isotope_Analysis.R` script.

### Contents:
* **`31_full_reconstruction/`**: Contains the finalized CSV outputs for the reconstruction, including:
  * `31_SIA_predator_samples_FINAL.csv` - Predator SIA values.
  * `31_SIA_predator_summary_FINAL.csv` - Summary statistics for predators.
  * `31_SIA_reference_individuals.csv` - Baseline reference individual data.
  * `31_SIA_reference_summary_FINAL.csv` - Summary statistics for baseline references.
